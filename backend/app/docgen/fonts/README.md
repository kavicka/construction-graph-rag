Font pre generované PDF: **JetBrains Mono** (mono štítky, dátumy, čísla) — rovnako ako
`--font-mono` v témě aplikácie (`frontend/src/index.css`). Telo dokumentu je `system-ui`
(`--font-sans`), ktoré sa nebalí — berie sa systémový font stroja, kde PDF vzniká.

Zdroj: [Fontsource](https://fontsource.org) (`latin` + `latin-ext` subsety, váhy 400 a 700),
licencia SIL Open Font License 1.1 (plné znenie v `OFL.txt`). `-latin` = základná latinka, `-ext` = č š ž ľ ť ň ď ĺ ŕ…
